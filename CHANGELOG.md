# Changelog

## v1.4.0
- Adaptive 2×2 cards on tall displays and four explicit settings tabs otherwise.
- Dynamic wrap for all settings descriptions and media option labels.
- Compact action menus retain result space on smaller monitors.
- Added optional fail-closed trusted Windows signature validation in GitHub Actions.
- Clarified legitimate Microsoft Store packaged MSIX distribution for reducing SmartScreen interruptions.

## v1.4.0

- Multiple excluded folders (allowlist), with optional traversal skip and post-scan result filtering.
- Safe exclusion enforcement for smart selection, manually marked files, and move-to-trash plans.
- Exclusion-scoped scan history and media rescan.
- Updated English and Chinese UI labels and shorter discovery-oriented README.
- Windows security/signing guidance aligned with Microsoft SmartScreen reputation rules.

## v1.2.0

- Responsive muted-pastel interface, clearer checkbox indicators and high-DPI improvements.
- Separate Traditional Chinese and English Windows EXE builds.
- Optional Windows signing support and updated GitHub Actions.
